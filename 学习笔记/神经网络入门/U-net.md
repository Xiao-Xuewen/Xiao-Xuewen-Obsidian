# 0. 什么是U-net?
我们知道经典的CNN 是什么样的结构[[CNN]]，一个大尺寸的图像经过CNN网络会不断的被提取特征 尺寸也不断的缩小 这其实就是一个**下采样**的过程，那么最后我们得到的是一个小尺寸的图 我们再做分类 这没问题 ，但是去噪不一样 我们最后不是输出一个什么标签 而是输出一个去过噪声的图像 是一个大小不变的图像 那么我们在下采样完成之后就需要将图像恢复到原来的大小 这其实就是一个**上采样**的过程，但是在上采样的时候由于我们下采样经过了池化 图像的特征有被抛弃的了 那么恢复的时候有些地方没信息啊 这个时候就需要skip connection，在下采样的过程中我们保留高分辨率的图像在上采样的时候进行concat来将上采样缺失的信息进行补充，整个的数流经过编码器从下采样从上到下，再经过解码器上采样从下到上，形成了一个"U"型，所以这个网络就叫U-net。
# 1. 编码器和解码器（Encoder and Decoder）
## 1.1 Encoder
这里的编码器其实和CNN的结构很像，主要的区别是两点：
- 最后不需要全连接层连接输出层 而是连接解码器
- 每个Encoder block中先做两层卷积再做池化
第一个不同很好解释了 因为去噪网络不是要分类 所以最后要通过解码器回归尺寸
第二个为什么要在池化前做两层卷积 首先我们知道池化就是要压缩特征了 也就是下采样了 降低图像的分辨率了 那么在这之前我们想要让特征图增加特征表达能力，一般使用两层卷积在进入池化
另外进入池化前必须要保留高分辨率的feature map到时候还得skip connection给解码器 最后的最后一般来一个bottleneckconv不做池化 只提高卷积核的数量 这样解码的时候能对称
## 1.2 Decoder
解码器是把特征图恢复到原图用的 那他是怎么做的呢 最关键的是**转置卷积**，

$$
H_{out}​=(H_{in​}−1)×stride−2×padding+kernel_{size}
$$

这是转置卷积的公式 我们设定好参数即可将特征图放大，那么具体是怎么做的呢我们看一个例子，这就是一个把图像放大两倍的转置卷积：

```
      self.up = nn.ConvTranspose2d(

            in_channels = input_channels,

            out_channels = output_channels,

            kernel_size = 4,

            stride = 2,

            padding = 1

        )
```
我们先不看输入输出通道 这个和图像大小无关 我们关注后面三个参数
他具体的操作是什么呢 比如一块2×2的图像 我们现在放大
