## 三、命令行参数argparse
1. 作用：可以使用命令行在执行python脚本时**传入相关的参数来控制脚本执行的情况**
2. 创建一个命令行解析器：`parser = argparse.ArgumentParser()`名字叫parser
3. 添加参数：参数名 参数数据类型 默认值
```
parser.add_argument(
    "--delay",
    type=float,
    default=0.05
)
```
4. 接受参数并使用：
5. 
```
args = parser.parse_args()
args.delay args.count args.desc可以作为变量参与
```
## tqdm进度条
1. 直观的**显示程序运行的情况**
2. 例子：
```
for i in tqdm(range(args.count),desc=args.desc):
    time.sleep(args.delay)
```
- 其中tqdm()就是给整个for循环加上了一个进度条 他是嵌入到for之中的，**for每完成一次循环 进度条增加一次** 
- desc:是进度条名字 time.sleep()类似单片机的delay() 这里主要是演示作用 直观的观察进度条的变化
