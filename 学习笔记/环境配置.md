## 1. 粗略的过一下README
简单看一下python,pytorch,CUDA,requirement......
## 2. 起手式 创建Conda环境
进入终端默认再base环境中 输入：`conda create -n sn2n python=3.10 -y`创建一个名字叫sn2n的python版本是3.10的Conda环境，
然后激活：`conda activate sn2n`
检查：`python --version`应该是python 3.10.x
更细一些的检查：`where python`地址应该在你Miniforge的envs里面 例如：`C:\Users\xxx\miniforge3\envs\sn2n\python.exe`
## 3. 更新基本安装工具
`python -m pip install --upgrade pip setuptools wheel`
养成使用`python -m pip install`而不是`pip install`的习惯
## 4. pytorch与CUDA
这里要注意的是也许我们的显卡和作者的显卡不一样 支持的CUDA版本也不一样 这时候我们需要集合我们的GPU以及pytorch和python综合安装 但安装之前一定要确定是配套的 查看 NVIDIA GPU/驱动使用`nvidia-smi`
安装pytorch:
`python -m pip install torch==... torchvision==... torchaudio==... --index-url https://download.pytorch.org/whl/cuXXX`
安装CUDA Runtiome 的pytorch wheel：
```
python -m pip install torch==<版本> torchvision==<版本> \
    --index-url https://download.pytorch.org/whl/cuXXX
```
一些的深度学习项目不需要安装CUDA Tollkit,一般只需要轮子和显卡驱动即可
检查：`python -c "import torch; print(torch.cuda.is_available())"`输出为True即可
但有些也需要安装 需要视README的具体情况而定，
总之，在安装之前一定要确定好各个模块的兼容性再安装！！！
万能检查指令：
```
python -c "import torch; print('torch:',torch.__version__); print('torch CUDA:',torch.version.cuda); print('CUDA available:',torch.cuda.is_available()); print('GPU:',torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'None'); print('cuDNN:',torch.backends.cudnn.version())"
```
更细的可以检查一下是否可以进行GPU计算：
```
python -c "import torch; x=torch.randn(1000,1000,device='cuda'); y=x@x; print(y.device, y.shape)"
```
应该输出：`cuda:0 torch.Size([1000, 1000])`
## 5. python项目依赖

打开requirements.txt先过一下，看一下有没有torch、torchvision、torchaudio因为刚才安装好pytorch 这里如果直接`python -m pip install -r requirements.txt`会安装这里指定的新的pytorch 没有的话直接`python -m pip install -r requirements.txt`
就行了
## 6.python依赖的其他情况
### 6.1 environment.yml
如果有这个文件 环境都不用先建了 直接`conda env create -f environment.yml`然后
`conda env list`查看环境名字，然后激活`conda activate 环境名`
### 6.2 pyproject.toml
通常进入项目根目录：`cd project_directory` 
然后`python -m pip install -e .`这是需要改源代码的情况
只是使用可以`python -m pip install .`
### 6.3 setup.py
和pyproject.toml一样
### 6.4 报错
手动更新依赖
删除：`python -m pip uninstall <PKG>`
安装：`python -m pip install <PKG>==<VER>`

# CUDA 三个版本一定要区分

| 指令 | 查看什么 | 含义 |
|---|---|---|
| `nvidia-smi` | NVIDIA Driver / GPU | 其中显示的 CUDA Version 主要表示当前驱动支持的 CUDA 能力 |
| `nvcc --version` | CUDA Toolkit | 本机真正安装的 CUDA 编译工具链版本 |
| `python -c "import torch; print(torch.version.cuda)"` | PyTorch CUDA Runtime | 当前 PyTorch wheel 对应的 CUDA Runtime |
| `python -c "import torch; print(torch.cuda.is_available())"` | PyTorch 能否使用 GPU | 最常用的 GPU 可用性检查 |

> **这几个版本不完全一样不一定有问题。**
>
> 普通 PyTorch 项目往往只需要：
>
> `NVIDIA Driver + CUDA 版 PyTorch Wheel`
>
> 如果项目需要编译 `.cu` / CUDA Extension，才通常需要额外关注：
>
> `CUDA Toolkit + nvcc + C/C++ Compiler + CUDA_HOME`

# 常见报错快速定位

| 报错 / 现象 | 第一批检查指令 | 常见原因 |
|---|---|---|
| `ModuleNotFoundError` | `python -m pip show <PKG>` | 包没装 |
| `ModuleNotFoundError` | `python -c "import sys; print(sys.executable)"` | VS Code / Python 环境选错 |
| `torch.cuda.is_available() == False` | `nvidia-smi` | Driver / GPU 问题 |
| `torch.cuda.is_available() == False` | `python -c "import torch; print(torch.__version__,torch.version.cuda)"` | PyTorch 装错版本或 CPU 版 |
| `nvcc is not recognized` | `where nvcc` | CUDA Toolkit 没安装或 PATH 问题 |
| `CUDA_HOME is not set` | `nvcc --version` | 项目需要编译 CUDA Extension |
| `cl is not recognized` | `where cl` | Windows C++ Build Tools 环境问题 |
| `Microsoft Visual C++ required` | `cl` | 缺少 MSVC / Build Tools |
| `DLL load failed` | `python -m pip check` | 二进制库版本冲突 |
| `Dependency conflict` | `python -m pip check` | Python 包版本不兼容 |
| `CUDA out of memory` | `nvidia-smi` | GPU 显存不足 |
| `CUDA out of memory` | `python -c "import torch; print(torch.cuda.memory_summary())"` | 检查 PyTorch 显存占用 |
| Terminal 能运行，VS Code 不能运行 | `python -c "import sys; print(sys.executable)"` | VS Code Interpreter 选择错误 |
| 环境越修越乱 | `conda env remove -n <ENV>` | 建议直接重建干净环境 |
