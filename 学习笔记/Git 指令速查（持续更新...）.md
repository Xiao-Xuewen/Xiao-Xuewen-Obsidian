1. git init 初始化本地仓库
2. git status 查看当前状态
3. git add 文件名1 文件名2 暂存文件 
4. git add . 暂存当前目录下所有文件
5. git commit -m "message" 提交暂存区的文件
6. git log 查看完整日志
7. git push -u origin main 第一次push
8. git push 正常push
9. git switch -c 分支名 创建并转移新分支
10. git branch 查看分支
11. git switch 分支名 切换分支
12. git commit --amend -m "新的 commit message" 修改上一个commit的message
